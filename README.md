## 🚀 Getting Started

### Prerequisites
* Download and install the [Godot Engine](https://godotengine.org/download/) (ensure you are using the correct major version for this project).
* If you plan to utilize the custom scripts in the `tools/` directory, ensure you have Python and Node.js installed on your machine.

### Installation
1.  Clone this repository:
    ```bash
    git clone [https://github.com/jchildree/Solatice-Gam-Jam-26.git](https://github.com/jchildree/Solatice-Gam-Jam-26.git)
    ```
2.  Open the Godot Engine.
3.  Click **Import** and navigate to the cloned directory to select the `project.godot` file.
4.  Click **Import & Edit** to open the project in the editor.
5.  Press `F5` (or click the Play button in the top right) to run the main scene.

   OR

   **Navigate to:** [Solitice](https://jchildree.itch.io/solitice-game-jam-26)
