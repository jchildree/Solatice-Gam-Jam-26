# Toggle drains DuskTimer

Each day/night Toggle deducts seconds from the active DuskTimer. We chose this over a free toggle because it makes the player manage Toggle as a resource -- spending time to reveal new paths -- which ties the solstice theme to a mechanical tradeoff rather than pure aesthetics. The alternative (independent systems) would let players spam-toggle to trial-and-error every platform with no cost.

## Considered options

- **Coupled (chosen):** each Toggle costs N seconds from DuskTimer. Toggle = solve path AND spend time.
- **Independent:** Toggle free, DuskTimer runs separately. Toggle = pure puzzle tool, dusk = separate pressure.
