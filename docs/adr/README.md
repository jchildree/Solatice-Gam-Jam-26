# Architectural Decision Records

ADRs document significant architecture decisions for this project.

## Format

Each ADR is a file named `NNN-short-title.md` with this structure:

```markdown
# NNN - Title

**Status:** proposed | accepted | deprecated | superseded

## Context

Why this decision was needed.

## Decision

What was decided.

## Consequences

What changes as a result.
```
